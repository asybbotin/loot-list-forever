# Loot List Forever

A **WoW: Forever** addon for compact item and money notifications, group-loot
voting, and dungeon/raid loot history. See each winner’s class, Need or Greed
choice, and winning roll. Auto Loot stays unchanged.

## Install

Place the `loot_list_forever` folder in your client’s `Interface/AddOns` directory
and enable **Loot List Forever** on the AddOns screen.

## Use

- **Settings:** type `/lootlist` or left-click the loot-bag minimap button. Adjust
  rarity filters, duration, opacity, and the group-loot toggle.
- **Move and resize:** drag the list handles. Settings and positions are saved.
- **Group rolls:** click **Need**, **Greed**, or **Pass** beside an item.
- **Run history:** type `/lootlist history` or right-click the minimap button.
  History survives reloads and clears when you leave the dungeon or raid.
- **Item links:** hover for tooltips; Shift-click to insert a link into chat.

Preview group rolls with `/lootlist grouptest` and history with
`/lootlist historytest`. Samples never submit real votes.
